Personaliza el nombre del evento, la clave de acceso y la sincronización en la nube.

📋 SQL para crear la tabla en tu proyecto Supabase (SQL Editor): 
create table if not exists public.invitados (
  rut text primary key,
  nombre text not null,
  acreditado boolean default false,
  hora_acreditacion timestamptz,
  origen text default 'excel'
);
alter table public.invitados enable row level security;
create policy "Acceso publico acreditacion" on public.invitados
  for all using (true) with check (true);
alter publication supabase_realtime add table public.invitados;
